# Ololade Berachiah Joseph — Personal Portfolio

> **Research & Data Consultant** | *evidence you can defend.*

Production-quality academic editorial portfolio website for **Ololade Berachiah Joseph**, designed as a **Dark Editorial Academic Ledger** with Fraunces serif typography, IBM Plex Mono archival metadata, and Inter body text.

---

## 🏛️ Project Overview

- **Design Philosophy**: Academic ledger × research archive × editorial data consultancy.
- **Color Palette**:
  - Main Charcoal: `#0F1214`
  - Surfaces: `#171B1E`
  - Hairline Borders: `#2A2F33`
  - Primary Typography: `#ECEAE4`
  - Warm Amber Accent: `#C98A3E`
  - Muted Sage Accent: `#5B8C7B`
- **Typography**:
  - Headlines: *Fraunces*
  - Body: *Inter*
  - Data / Monospace: *IBM Plex Mono*

---

## 🧭 Pages & Routes

1. **Overview / Home (`/`)**: Main editorial hero, 5-stage research workflow, featured case studies preview, and field notes snapshot.
2. **About (`/about`)**: In-depth academic profile, pharmacology foundation, NYSC Biology teaching experience, and `FIELD NOTES / 001` ledger.
3. **Selected Work (`/work`)**: 10 anonymized research case studies spanning pharmacology, toxicology, legume nutrition, physiology, nursing survey, and SPSS data cleaning with interactive discipline filters.
4. **Skills & Tools (`/skills`)**: 3-column academic capabilities and in-depth software toolkit breakdown (SPSS, GraphPad Prism, Excel, Python in progress).
5. **Contact (`/contact`)**: Direct channels (Email, Phone, LinkedIn, CV), consultation scopes, and interactive project scoping helper.
